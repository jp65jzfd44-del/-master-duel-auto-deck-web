# マスターデュエル 自動デッキビルダー Safari / PWA版

iPhoneのSafariから使う暫定版です。

- AltStoreの3アプリ上限を使いません
- 7日ごとの再署名は不要です
- 「共有」→「ホーム画面に追加」でアプリのように起動できます
- Apple Developer Programが有効になったら、ネイティブiPhone版へ移行する予定です

## 主な機能
- 日本語テーマ
- フリー検索
- カード画像
- Master Duelの N / R / SR / UR表示
- ネタデッキ（パチンコ型など）
- 構築理由
- 基本の動かし方
- JSON / YDK出力

公開サイトはGitHub Pagesで配信します。
